LinClone logo package
=====================
mark/  — the logo mark on transparent background (use inside the app UI)
  linclone-mark-full.png        original resolution (751x795)
  linclone-mark-512/256/128/64  pre-scaled sizes
  linclone-mark-mono-white.png  one-color white (dark surfaces, print)
  linclone-mark-mono-black.png  one-color dark  (light surfaces, print)

app-icon/ — gradient mark on white rounded tile (store icon)
  appicon-1024  App Store / Play Store master
  appicon-512   Play Store listing
  appicon-192   Android launcher (xxxhdpi)
  appicon-180   iOS @3x (60pt)
  appicon-167   iPad Pro
  appicon-152   iPad
  appicon-120   iOS @2x (60pt)
  appicon-48    small / favicon base

Note: source artwork is raster (PNG). No vector (SVG/AI) master exists —
if you need one for print at large sizes, have the mark redrawn in vector.
In-app UI screens use linclone-mark-full.png (assets/354d3645.png).
